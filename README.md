# 🤖 Robot Framework + Browser Library: Estudo de Automação BugBank

## 🚀 Sobre o Projeto

Este repositório é dedicado ao estudo e prática da automação de testes End-to-End (E2E) utilizando o **Robot Framework** em conjunto com a **Browser Library** (que utiliza o Playwright internamente).

O projeto automatizará fluxos críticos na aplicação de demonstração **BugBank** (URL: `https://bugbank.netlify.app/`), que simula um sistema bancário.

### 🎯 Fluxos de Automação Focados

Os testes E2E neste estudo cobrirão, mas não se limitarão a:

* **Criação de Conta:** Cadastro de novos usuários.
* **Login e Logout:** Acesso e saída do sistema.
* **Transações:** Realização de transferências e depósitos.
* **Validações:** Conferência de saldos e extratos.

### 💡 Objetivos de Estudo e Aprendizado

1.  Dominar as palavras-chave (Keywords) da Browser Library.
2.  Implementar o padrão Page Object Model (POM) para manter o código limpo e escalável.
3.  Praticar a manipulação de dados de teste.
4.  Entender a geração de relatórios de alta qualidade do Robot Framework.

## 🛠️ Tecnologias Principais

Este projeto se baseia nas seguintes ferramentas modernas de automação:

* **Robot Framework:** Framework de automação de código aberto.
* **Browser Library:** Biblioteca moderna e robusta para Web Automation, potencializada pelo **Playwright**.
* **Python:** Linguagem subjacente utilizada pelo Robot Framework.
* **Node.js/npm:** Utilizado para gerenciar as dependências do Playwright.
